# Инструкции для AI-агентов

Перед изменением кода приложения прочитай и соблюдай
[правила разработки по Simple Architecture](./docs/simple-architecture.md).

## Задания

Домашние задания и таски находятся в [папке `tasks`](./course-tasks/). Назначение
папки описано в её [README](./course-tasks/README.md).

Когда пользователь просит выполнить задание, таску или ДЗ:

1. Сначала просмотри содержимое `tasks/`.
2. Найди и полностью прочитай относящийся к запросу файл задания.
3. Используй его требования вместе с текущим запросом пользователя.
4. Если подходят несколько файлов и нужное задание нельзя определить из
   контекста, уточни выбор до изменения кода.

Прямые указания пользователя в текущем запросе имеют приоритет над текстом
файла задания.
