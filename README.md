# TV Shows Explorer

Базовый React-проект для учебного задания по архитектуре. Реализация поиска,
пагинации и фильтрации пока не добавлена.

## Стек

- React
- TypeScript
- Vite
- TanStack Query
- ESLint

## Запуск

```bash
npm install
npm run dev
```

## Команды

```bash
npm run lint
npm run build
npm run preview
```

## Структура

- `src` — исходный код приложения;
- `docs` — документация проекта;
- `tasks` — файлы с домашними заданиями;
- `lecture-notes` — конспекты лекций;
- `AGENTS.md` — инструкции для AI-агентов (пока пустой).
