:house: Homework #2 — From Frontend to Fullstack

Продолжаем развивать наш TV Shows Explorer. На этот раз добавим собственный backend, перенесём на него часть логики, реализуем кеширование и добавим избранное.

1. Обновляем AI Rules

Обновите ваши AI Rules с учётом новых знаний из второй лекции. Архитектура развивается — AI должен понимать новые правила и следовать им.

2. Создаём Backend

Добавьте собственный backend-сервер и перенесите на него:


• Пагинацию..
• Фильтрацию по жанрам..
• Взаимодействие с TVmaze API..

Добавляем кеширование:


• Для хранения кеша используйте обычный объект const cache = {}..
• Если такой же запрос к TVmaze уже выполнялся в течение последних 5 минут, возвращайте данные из кеша..
• Если кеша нет или он устарел — обращайтесь к TVmaze и обновляйте его..

Цель — уменьшить количество запросов к внешнему API.

3. Добавляем избранное

У каждого шоу должна появиться звёздочка, позволяющая добавить его в избранное или убрать оттуда.

Требования:


• При добавлении или удалении показывайте Toast-уведомление..
• Добавьте кнопку, отображающую количество избранных шоу..
• По нажатию на кнопку пользователь должен иметь возможность просмотреть список избранного..
• Вся логика избранного должна находиться на backend..
• Для хранения используйте обычный объект const favorite = {}..

Базы данных пока не нужны — храним всё в памяти сервера.

4. Обновляем архитектуру

Обновите весь проект с учётом второй лекции. Особое внимание уделите распределению ответственности между frontend и backend и правильному размещению бизнес-логики.
