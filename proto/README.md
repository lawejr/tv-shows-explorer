# Прототипы страницы поиска

Четвёртая итерация: две сохранённые темы и два пространственных интерфейса.

1. **DOS / TV** — сохранённый синий ретроинтерфейс.
2. **Кинозал / ЗАЛ 01** — сохранённый тёмный кинозал.
3. **Видеопрокат / Последний сеанс** — полка с физическими VHS-кейсами, CRT-телевизор и стойка кассира.
   Найдите сериал и нажмите на кассету: она поднимется с полки, а описание появится на телевизоре.
4. **Киновселенная / Кинокосмос** — настоящая Canvas 2D сцена с плавающими обложками.
   Перетаскивайте пространство мышью или пальцем, масштабируйте колесом или кнопками +/−.
   Кнопка ⌖ возвращает исходный вид. Нажатие на обложку открывает описание.
   Для клавиатуры доступны те же сериалы кнопками в нижней части сцены.

Прямые ссылки: `#dos`, `#cinema`, `#rental`, `#universe`.
Пустой старт, поиск, жанры и три результата на страницу сохранены во всех темах.
Декоративные кассеты на нижней полке не являются поисковой выдачей.
Анимации отключаются при `prefers-reduced-motion`; canvas при этом перерисовывается только при изменениях.
При смене темы освобождаются анимационный цикл, обработчики и ResizeObserver.

Запуск из корня проекта: `npm run dev`, затем открыть `/tv-shows-explorer/proto/` (с учётом `base` проекта).
Можно также раздать эту папку любым статическим HTTP-сервером. Сборка и новые зависимости не нужны.

Переключатель сверху сохраняет запрос, жанр и страницу. Кнопка «Показать выдачу» запускает поиск `Murder`.
Стартовый экран пустой. Поиск выполняется по Enter или кнопке, фильтры собираются из найденных сериалов,
пагинация показывает по 3 результата. Escape очищает поиск. Доступны загрузка и пустая выдача.

Это **дизайн-прототип**, а не выполненное ДЗ: используется небольшой локальный набор примеров из `data.js`,
поиск работает по вхождению в название. Рейтинги и описания иллюстративные; SVG-обложки нарисованы для макета.
TVmaze, сетевые ошибки, реальная отмена запросов и прикладная React-архитектура будут реализованы после выбора дизайна.

Все файлы изолированы от `src`. `view.js` отвечает за разметку, `app.js` — за состояние и взаимодействия,
`art.js` — за SVG-обложки. Новые концепции изолированы в `new-concepts.js`, `new-shell.js`, `scenes.js`
и `new-themes.css`: тексты, композиция, декоративные сцены и анимированные адаптивные темы соответственно.

Пространственные интерфейсы: `immersive.js` и `immersive.css`; управление canvas — `universe.js`, отрисовка — `universe-render.js`.
